## 最终结构与实际调用

正式链为 Controller/五个Behavior速度端点 → Velocity Smoother → Collision Monitor直接私有Stamped candidate → Gate → 私有final Twist → 唯一execution_bridge → 私有GZ drive → DiffDrive。candidate_relay仅保留隔离夹具，不在r20正式链。派生launch不启动docking，不改P0默认launch/Bridge/SDF；每轮核对类型、端点、GID、私有partition及执行端来源。

Mission API → Runtime owner → Store事务 → BeginLease持久意图 → ExecutionPort有界RPC → Gate挑战/授权 → owner事务ExecutionBind/SendAuthorized → 原NavigationAdapter唯一Action发送。续租每80ms通过业务owner的健康/状态/事务，ROS线程不能独立续命。Revoke、Action终态、D停止窗口分开进入owner，释放前复核Gate新鲜快照；恢复PAUSED/占槽且禁止自动重发。

Gate/Observer独立进程，单线程Executor；纯核心不建Node、不写DB、不发布。请求/候选/tick和publish在同一串行边界，避免Revoke后另一个输出线程发旧非零。steady/wall20ms watchdog不依赖ROS时钟；use_sim_time=false且显式关闭隐式clock线程，只消费校验过的Clock。参数初始化后冻结。

期限：lease300ms、challenge100ms、接收新鲜度200ms、来源年龄300ms、clock无进展300ms；max .2m/s、1rad/s及轮速12rad/s。Nav2新派生速度.18/.8留余量，不裁剪非法命令。D要求推进仿真时间≥3s，v≤.01m/s、w≤.03rad/s、位移≤.02m、yaw≤.03rad、最大来源间隙.5s、接收缺口200ms即重建、新鲜度200ms；最终零阈值.001。期限没有为失败而放宽。

Port命令32、关键事件64、pending RPC8/250ms、context64、幂等effect4096，满即fault锁存并拒绝发送/续租，仍允许应急撤销/精确取消。Begin历史64不LRU复活旧请求。相同request幂等不刷新期限；新授权清缓存，旧stamp/epoch/generation不能复用。

DB故障不虚构成功接纳。存储无法写入时应急revoke/cancel明确为NOT persisted并保留stderr，正常任务状态/事件/effect仍以事务提交为前提；Gate独立租约是最终失效兜底，不宣称数据库与DDS原子提交。
