# 核心测试设计

测试通过运行时 check 抛出异常并返回非零退出码；不依赖 assert，Release/NDEBUG 下也有效。每个 CTest 名称对应一组相关合同。预期值来自独立几何结果、接口契约或运动可逆性，不复制实现中的中点角/sinc 公式。

| 组 | 反例与预期依据 |
|---|---|
| straight | 朝北从 (1,2) 以 0.5 m/s 走 2 s 到 (1,3)；倒车到 (0,2)；dt=0 恒等；负/NaN/Inf dt、逐坐标 NaN 状态、Inf 状态、非有限控制抛 invalid_argument；有限输入导致输出溢出抛 overflow_error |
| arc | 单位圆正/负转向四分之一弧到 (1,±1)、倒车到 (-1,-1)；纯旋转位置不动；整圆回到原点且航向归一；相反 v/w 以正 dt 返回任意初始位姿，负 dt 仍非法 |
| near_zero | w=0、±1e-12 收敛到直线；在半角分支两侧采用小角几何界 abs(x-1)<=w²/6、abs(y)<=abs(w)/2 和转向符号检查，不复用被测公式 |
| wheels | 示例左右轮为 (1,9) rad/s；纯旋转 (-4,4)、倒车 (-5,-5)；极限 9 接受、8 拒绝；零/负/非有限轮径、轮距与上限；NaN 指令和溢出轮速拒绝 |
| gate | 初次 seq=0 和 created 时刻可接受；99 ms 接受、100 ms 到期拒绝、101 ms 拒绝；重复/乱序拒绝；未来时间戳拒绝；零/负/超过 max TTL 拒绝；恰等于 max TTL 的配置有效；NaN/Inf 拒绝；修复时间/TTL/数值后相同序号可重用 |

Gate 所有时间均为 steady_clock 合成时间，不 sleep，不依赖 ROS 或仿真时钟。TTL 比较对象是毫秒 duration，不使用跨主机时间；测试没有证明主动定时停车或多线程安全。

最终工作树只保留新版核心：按作者要求，旧 command_policy 头文件和测试已移除，不再运行旧策略或依赖 ament_cmake_gtest。旧测试曾通过的历史记录保留在此前证据目录，不计入最终新版验收。新版有效时间区间为 [created, created+ttl)，到期即拒绝；拒绝不消耗序号。

独立构建只要求 CMake/C++17 和 CTest，完全隔离 ROS；ROS 构建运行同样五组新测试。最终验收使用新的独立/colcon 构建目录，不能引用删除旧源码前的报告。colcon test-result 最终应为 5 tests，无旧 GTest XML。

另用安装后的 cmr_core::cmr_core 目标构建默认请求 C++11 的小消费者，使用编译期 static_assert 检查实际为 C++17，并运行验证目标导出与新版头文件可用性。消费者为构建验收产物，保存在专用 build 目录，不添加产品空包。
