# P0-07 数学与工程审查

两圆有符号间距 d=||po-pr||-(Rr+Ro)。负数是圆模型重叠，不是真实车身穿透深度。

令q0=po(t0)-pr(t0)，q1=po(t1)-pr(t1)，u=q1-q0。在线性段模型下，alpha=clip(-q0·u/(u·u),0,1)，dmin=||q0+alpha*u||-Rr-Ro。u=0时返回起点，退化时间只允许端点一致。实现先用最大分量缩放u，再比较两端导数符号，避免极小非零u平方下溢。tmin只是closest_approach，不求首次接触根。

独立预期（半径和1）：q=(2,0)恒定→1；(1,0)→0；(.75,0)→-.25；(-2,0)→(2,0)两端1、内部-1/alpha=.5；(-2,1)→(2,1)内部相切0；(2,0)→(3,0)起点1；中心重合→-1。共同平移/旋转及交换对象不得改变距离。

上述是工程数学oracle，不是用户手算。后续独立工程脚本不得import被测几何函数；用高精度凸函数搜索和原始数据重建核对。真实没有内部极小/缺口案例时，用明确fixture补测。
